## Multilanguage-Dictionary 
This is a simple Multilanguage-Dictionary Web-App which i have made through HTML, CSS and JS .It gets data from api and displays it through frontend. I have used Dictionary API through https://dictionaryapi.dev/ this website  and also i have used 
web audio API for translation from voice.
